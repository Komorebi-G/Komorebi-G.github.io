## Andrew 凸包

来回扫两遍，左右转只需要保持一致即可。

## 板子

```cpp
sort(points.begin(), points.end());

vector<Point> stk;

for (auto p : points)
{
    while (stk.size() >= 2 &&
           cross(stk.back() - stk[stk.size() - 2],
                 p - stk.back()) <= 0)
        stk.pop_back();

    stk.push_back(p);
}

int lower_size = stk.size();

for (int i = n - 2; i >= 0; i--)
{
    auto p = points[i];

    while (stk.size() > lower_size &&
           cross(stk.back() - stk[stk.size() - 2],
                 p - stk.back()) <= 0)
        stk.pop_back();

    stk.push_back(p);
}

stk.pop_back();
// 注：这里最后得到的就是凸包顺序。如果 A、B、C 共线，
// 那么 B 会被排除，只得到极点；如果要保留 B，则需要额外处理 cross == 0。
```
